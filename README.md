# Resume RAG Application

An AI-powered tool designed to streamline the resume screening process using Retrieval-Augmented Generation (RAG). This application allows users to upload PDF resumes and receive concise, context-aware summaries generated by Large Language Models (LLMs).

## 🚀 Features
- **PDF Resume Upload:** Seamlessly upload and process PDF resumes.
- **AI-Powered Summarization:** Leverages the `phi3` model via Ollama for intelligent summarization.
- **Modern UI:** Responsive frontend with a clean Neumorphism design.
- **RAG Architecture:** Built with a foundation for advanced document retrieval and analysis.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Axios, Vanilla CSS.
- **Backend:** FastAPI (Python), LangChain.
- **AI/LLM Support:** Ollama (`phi3` model), Embeddings (`phi3`).
- **Vector Database:** Qdrant.

## 🧠 Skills Demonstrated
- **Full-stack Development:** Integration of a React frontend with a FastAPI backend.
- **Generative AI & RAG:** Implementing document loaders, text splitters, and LLM orchestration using LangChain.
- **API Design:** Developing robust RESTful endpoints for file processing and data retrieval.
- **UI/UX Design:** Implementing modern design trends like Neumorphism for an enhanced user experience.
- **Tooling & Orchestration:** Utilizing Ollama for local LLM deployment and experimentation.

## 🔮 Future Plans
- **Vector Store Integration:** Enable efficient storage and retrieval across a large corpus of resumes.
- **Search & Compare:** Functionality to search within resumes and compare multiple candidates side-by-side.
- **Export Capabilities:** Option to export summaries and comparisons for HR reporting.
